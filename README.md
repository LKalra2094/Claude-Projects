# Claude Projects

This repo holds the shared standards and templates that every project follows. No application code lives here.

## What's inside

- **Claude.md** defines the project lifecycle, folder structure, sprint workflow, and commit conventions that all projects inherit.
- **Templates** provide starting points for product briefs, PRDs, backlogs, and session handoffs. Each project copies from these when creating new docs.

## Where the code lives

Each project gets its own folder, its own git repo, and its own GitHub repo. They appear as subfolders here locally but are tracked independently. Check each project's repo for its source code, sprint history, and documentation.
